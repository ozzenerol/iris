## A client

An `s3.Client` holds the keys, the region and, for a server other than AWS, its `endpoint`. With an endpoint the bucket is the first part of the path (`http://localhost:9000/photos/a.jpg`); without one it is part of the host name (`https://photos.s3.eu-west-1.amazonaws.com/a.jpg`). Every task and thread can share one client:

```iris
import s3

!void main() {
    c := s3.Client{endpoint: "http://localhost:9000", accessKey: "minioadmin", secretKey: "minioadmin"}
    defer c.close()

    try c.put("photos", "cat.txt", "meow", "text/plain")
    scoped String back = try c.get("photos", "cat.txt")
    print(back)
}
```

## Calls

- `createBucket` and `deleteBucket`.
- `put`, `get`, `getRange`, `head`, `exists` and `delete` for objects.
- `list` for a page of the objects under a prefix, with `delimiter` to group them as folders.
- `putLarge`, and `startUpload` with `Upload.part`, `finish` and `abort`, for objects sent in parts.
- `presign` for a URL that works without keys for a limited time.

Errors are `S3Error.notFound`, `denied`, `conflict`, `invalid` or `failed`, with the server's message and code.
