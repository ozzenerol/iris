# Language

A tour of Iris, one topic per page. Each page builds on the ones before it.

1. [A first program](first-program.html): `main`, printing, comments and statements.
2. [Variables and types](variables-and-types.html): declaring values and the built-in types.
3. [Functions](functions.html): parameters, default and named arguments, several return values.
4. [Control flow](control-flow.html): `if`, `for` and `match`.
5. [Text](text.html): `str`, `String` and putting values into strings.
6. [Structs](structs.html): fields, literals, methods and embedding.
7. [Enums](enums.html): plain enums and enums that carry data.
8. [Pointers and memory](pointers-and-memory.html): pointers, slices, allocation, `defer` and `scoped`.
9. [Errors](errors.html): `!T`, `try` and `catch`.
10. [Generics](generics.html): generic structs and functions, interfaces.
11. [Modules](modules.html): splitting a program up and using packages.
12. [Compile time](compile-time.html): `const`, `comptime`, `when` and attributes.
13. [Concurrency](concurrency.html): tasks, channels, threads and atomics.
14. [Calling C](calling-c.html): C headers, callbacks, assembly and SIMD.
15. [Tools](tools.html): the `iris` command, tests and builds.
