Roadmap

Each step is a release. A release is made when everything in it works and the tests pass on Linux x86_64, Linux arm64 and macOS arm64.

VersionContentsStatus
0.1Lexer and parser for the whole syntax. iris parse prints the syntax tree.released
0.2Integers, bool, functions, default and named arguments, if, for, match, const, string literals, print and panic. The first programs that run.released
0.3Pointers, structs, methods, embedding, arrays, slices, String, format, alloc, free and type aliases. Use after free is caught in debug builds.released
0.4!T, try, catch, defer, errdefer, scoped, error traces, and plain enums for error codes.released
0.5Enums with data, flag enums, patterns that take values apart, and several return values.released
0.6Generic structs and functions, interfaces as bounds, and dyn.released
0.7Modules, projects, packages with iris get, and the first standard library modules: io, fs, str and os.released
0.8import c: C headers read with clang, C functions (also with ...), structs, types and constants, and linking C libraries.released
0.9Floating point: f32, f64, the math module, str.parseFloat, and C's float and double.released
0.10Functions as values, callbacks from C, and @export.released
0.11Tasks, channels, select, sleep, and the net and http modules.released
0.12Text with values passed straight to str parameters, http.serve on every CPU core, and io_uring on Linux.released

After 0.12, in no fixed order: threads started by the program, atomics and locks, comptime and when, attributes like @json, iris fmt, the language server, and a JIT for iris run.
