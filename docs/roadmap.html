Roadmap

Each step is a release. A release is made when everything in it works and the tests pass on Linux x86_64, Linux arm64 and macOS arm64.

VersionContentsStatus
0.1Lexer and parser for the whole syntax. iris parse prints the syntax tree.released
0.2Integers, bool, functions, default and named arguments, if, for, match, const, string literals, print and panic. The first programs that run.released
0.3Pointers, structs, methods, embedding, arrays, slices, String, format, alloc, free and type aliases. Use after free is caught in debug builds.released
0.4!T, try, catch, defer, errdefer, scoped, error traces, and plain enums for error codes.released
0.5Enums with data, flag enums, the rest of match and several return values.next
0.6Generics and interfaces.planned
0.7Modules, packages, import c, and the first parts of the standard library (io, fs, str).planned

After 0.7, in no fixed order: comptime and when, attributes, tasks and the network library, iris fmt, the language server, and a JIT for iris run.
