    v0.51.0

    Roadmap

    Each step is a release. A release is made when everything in it works and the tests pass on Linux x86_64, Linux arm64 and macOS arm64.

    VersionContentsStatus
    0.1Lexer and parser for the whole syntax. iris parse prints the syntax tree.released
    0.2Integers, bool, functions, default and named arguments, if, for, match, const, string literals, print and panic. The first programs that run.released
    0.3Pointers, structs, methods, embedding, arrays, slices, String, format, alloc, free and type aliases. Use after free is caught in debug builds.released
    0.4!T, try, catch, defer, errdefer, scoped, error traces, and plain enums for error codes.released
    0.5Enums with data, flag enums, patterns that take values apart, and several return values.released
    0.6Generic structs and functions, interfaces as bounds, and dyn.released
    0.7Modules, projects, packages with iris get, and the first standard library modules: io, fs, str and os.released
    0.8import c: C headers read with clang, C functions (also with ...), structs, types and constants, and linking C libraries.released
    0.9Floating point: f32, f64, the math module, str.parseFloat, and C's float and double.released
    0.10Functions as values, callbacks from C, and @export.released
    0.11Tasks, channels, select, sleep, and the net and http modules.released
    0.12Text with values passed straight to str parameters, http.serve on every CPU core, and io_uring on Linux.released
    0.13thread, channels between threads, Atomic[T], Mutex and threadlocal.released
    0.14@json with the json module, Strings from calls freed at the end of the statement, and r"""...""".released
    0.15Debug information: gdb and lldb show Iris lines and values, and AddressSanitizer reports show Iris lines.released
    0.16when, --target, and fixes: catch takes one value, no copies of a Mutex or Atomic, and safer temporary text.released
    0.17iris fmt, and test blocks with expect and iris test.released
    0.18iris lsp, a language server, and syntax files for Vim and Neovim.released
    0.19List and Map, for over structs with next, the time module, and Durations that print in units.released
    0.20Folders, file information and files read a part at a time in fs, the path module, and process.run.released
    0.21An HTTP Router and an HTTP client.released
    0.22TLS: https for the HTTP client and server, and TLS connections in net.released
    0.23random, crypto (SHA-256, HMAC), base64, hex and url.released
    0.24The sqlite module. [] for an empty slice.released
    0.25comptime.released
    0.26iris doc, @env with the env module, @inline and @unchecked.released
    0.27HTTP handlers that can fail, res.error, Router middleware and after hooks, json.quote, sqlite.all and sqlite.one, and the log module.released
    0.28Timeouts on connections, server limits, Router.shutdown, and the signal module.released
    0.29Generic methods checked when used (List.contains, indexOf, freeEach, Map.keys), and channels with no buffer.released
    0.30WebSockets, http.Client with connections kept open, the csv module, crypto.sha1, and a guide to building a REST API.released
    0.31Command-line flags from @flags structs, the term module (colors, tables, progress, line editing), scoped name := value, and a guide to building a command-line tool.released
    0.32UDP, addresses, and a DNS resolver written in Iris that net.dial uses.released
    0.33HTTP/2 for the server and the client, with HPACK, flow control and ALPN.released
    0.34Regular expressions (regex), matched in linear time.released
    0.35Compression: deflate and gzip, and gzip in HTTP.released
    0.36A PostgreSQL driver written in Iris.released
    0.37A Redis client, and structs that hold a List of themselves.released
    0.38The documentation: the Language Tour, guides, and the library with a comment on every public name. Struct defaults everywhere, constant array sizes, integer limits, json.decode into slices.released
    0.39and, or and not as words, a condition after a statement (return -1 if n < 0), any number of arguments with T... name, Tour chapters on the everyday library, log fields, iris mod init, and completion of local names in the language server.released
    0.40is and is not for == and !=, and C names that are not, and, or or is imported with a _ after them.released
    0.41@noreturn (and os.exit can end a catch block), a clear error for a module that isn't imported, a fix for text built on one branch only, and go-to-definition on type names, module names, receivers and struct literal fields.released
    0.42str.format, and constants made of text with constants in braces (const Q = str.format("SELECT 1 FROM {TABLE}")), worked out when compiling.released
    0.43a if cond else b, a choice of value on one line (return true if rows == 1 else false).released
    0.44The Language Tour's examples come from networking and systems work, a guide that builds a TCP chat server, import c follows a macro defined as another macro (AF_INET on Linux), and a generic used with Duration and with i64 gets an instance for each.released
    0.45env.loadFile(path) reads a file of KEY=value lines into the environment, so an @env struct can be filled from a .env file.released
    0.46env.loadWith(Settings, ".env") reads a .env file when there is one and fills the @env struct in one call.released
    0.47A List field of a @json struct is read and written as a JSON array, and json.decode(List[T], text) reads an array into a new list.released
    0.48The functions of str are methods of str and String with no import: path.startsWith("/api"), line.trim(), "8080".parseInt(). The editor offers them after a dot.released
    0.49Conn.remoteAddr() and Conn.localAddr() say who is on each side of a connection, and req.remote is the address an HTTP request came from. fd() gives a socket's file descriptor for socket options.released
    0.50n++, n--, ++n and --n, usable as values: ports[count++] = 443.released
    0.50.1Go to definition and hover work on Error, e.code, e.message, error, print and the other built-in names.released
    0.51packed structs, align(n), bitfields (u8 version: 4), fields in network byte order (u16be, u32be, u64be), and sizeof(T), so a protocol header is read straight from the bytes.released
