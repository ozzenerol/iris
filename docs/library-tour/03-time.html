    Time

    The time module gives the current time, a clock for measuring, and dates: making them, taking them apart, writing them and reading them back. Lengths of time are Durations, the numbers with units like 250ms from Integers.

    Moments

    A time.Time is a moment: the nanoseconds since 1970-01-01 00:00 UTC, plus the time zone it is shown in.

    • time.now() gives the current moment in UTC.
    • time.unix(seconds) gives the moment that many seconds after 1970.
    • unix() and unixMs() give the seconds and milliseconds back.
    import time

void main() {
    t := time.unix(1700000000)
    print("{t} is {t.unixMs()} ms after 1970")

    now := time.now()
    print("now is later: {now.after(t)}")
}
    2023-11-14T22:13:20Z is 1700000000000 ms after 1970
now is later: true

    {t} writes a Time in ISO 8601. iso() and format give its text as a new String, in that form or another (see Writing a time).

    Dates

    time.date(year, month, day) makes a moment in UTC, with the month from 1 to 12. The hour, minute and second can follow and default to 0. year(), month(), day(), hour(), minute(), second(), nanosecond() and weekday() give the parts back. A day past the end of its month carries into the next month, and a month past 12 into the next year.

    import time

void main() {
    t := time.date(2026, 10, 17, 9, 30)
    print("{t.year()}-{t.month()}-{t.day()} {t.hour()}:{t.minute()}, a {t.weekday()}")

    leap := time.date(2026, 2, 29)
    print("{leap.month()}/{leap.day()}")
    print("{time.date(2026, 14, 1)}")
}
    2026-10-17 9:30, a saturday
3/1
2027-02-01T00:00:00Z

    weekday() gives a time.Weekday, an enum that starts with monday.

    Adding and comparing

    add(d) gives the moment a Duration later, or earlier when d is negative. sub(other) gives the Duration between two moments. before and after compare them.

    import time

void main() {
    start := time.date(2026, 10, 17, 9, 30)
    end := start.add(36h + 15m)

    print("{end.day()} at {end.hour()}:{end.minute()}")
    print("{end.sub(start)} later, {start.sub(end)} the other way")
    print("{start.before(end)} {start.after(end)}")

    yesterday := start.add(-24h)
    print("yesterday was the {yesterday.day()}th")
}
    18 at 21:45
36h15m0s later, -36h15m0s the other way
true false
yesterday was the 16th

    add counts elapsed time, so a day is always 24h. addDays(n), addMonths(n) and addYears(n) move on the calendar and keep the time of day. A day the new month doesn't have becomes its last day, so January 31 plus a month is February 28.

    import time

void main() {
    t := time.date(2026, 1, 31, 9, 30)
    print("{t.addDays(30)}")
    print("{t.addMonths(1)}")
    print("{t.addMonths(-2)}")

    leap := time.date(2024, 2, 29)
    print("{leap.addYears(1)}")
}
    2026-03-02T09:30:00Z
2026-02-28T09:30:00Z
2025-11-30T09:30:00Z
2025-02-28T00:00:00Z

    They count in the offset the moment is shown with. For t.local(), the day changes at midnight where the program runs.

    Writing a time

    • iso() writes a moment in ISO 8601, with the fraction of a second when there is one.
    • dateText() writes only the date.
    • format(layout) writes it with a layout made of YYYY, MM, DD, hh, mm, ss, SSS (milliseconds) and Z (the offset, Z for UTC). Other characters are copied.
    • format() with no layout is iso(), and {t} uses it.
    import time

void main() {
    t := time.date(2026, 10, 17, 9, 5).add(250ms)

    scoped String iso = t.iso()
    scoped String day = t.dateText()
    scoped String eu = t.format("DD/MM/YYYY hh:mm")
    scoped String log = t.format("hh:mm:ss.SSS Z")

    print(iso)
    print(day)
    print(eu)
    print(log)
}
    2026-10-17T09:05:00.25Z
2026-10-17
17/10/2026 09:05
09:05:00.250 Z

    Time zones

    A moment is the same in every time zone. The zone only changes how it is shown. local() shows it in the computer's time zone, utc() in UTC, and withOffset(seconds) with an offset in seconds east of UTC. The parts and the text follow the zone.

    import time

void main() {
    t := time.date(2026, 10, 17, 9, 30)
    rome := t.withOffset(2 * 3600)

    scoped String a = rome.iso()
    print("{a}, hour {rome.hour()}")
    print("same moment: {rome.unix() == t.unix()}")

    scoped String back = rome.utc().iso()
    print(back)
}
    2026-10-17T11:30:00+02:00, hour 11
same moment: true
2026-10-17T09:30:00Z

    Reading a time

    time.parse(text) reads ISO 8601: a date, a date and time with T or a space between them, seconds with a fraction, and an offset (Z, +02:00 or +0200). Without an offset the time is UTC. The moment it gives is shown with the offset it read. Text it can't read gives a time.TimeError.invalid with a message that says why.

    import time

!void main() {
    t := try time.parse("2026-10-17 11:30:00.250+02:00")
    scoped String u = t.utc().iso()
    print(u)

    d := try time.parse("2026-10-17")
    print("{d.weekday()}")

    for text in ["2026-13-01", "2026-02-30", "2026-10-1x"] {
        _ = time.parse(text) catch e {
            print("{e.code}: {e.message}")
            time.Time{}
        }
    }
}
    2026-10-17T09:30:00.25Z
saturday
TimeError.invalid: '2026-13-01' has no such month or day
TimeError.invalid: '2026-02-30' has no such month or day
TimeError.invalid: '2026-10-1x' has 'x' where a digit should be

    parse checks that the month has the day. 2026-02-29 is an error and 2024-02-29, in a leap year, isn't.

    Reading a duration

    time.parseDuration(text) reads a Duration written as Iris writes it: 1m30s, 250ms, 1.5h. A number alone is seconds. Use it for durations from a settings file or a database. Flags and @env fields read durations already (see Command-line flags).

    import time

void main() {
    for text in ["1m30s", "250ms", "1.5h", "30", "1m30", "soon"] {
        d := time.parseDuration(text) catch e {
            print(e.message)
            continue
        }
        print("{text} is {d}")
    }
}
    1m30s is 1m30s
250ms is 250ms
1.5h is 1h30m0s
30 is 30s
'1m30' isn't a duration like 30s or 1m30s
'soon' isn't a duration like 30s or 1m30s

    Measuring

    time.now() follows the computer's clock, which can jump when someone sets it. time.clock() reads a clock that only goes forward. The difference of two readings is a Duration, so use it to measure how long something takes.

    import time

void main() {
    start := time.clock()
    sleep(20ms)
    took := time.clock() - start

    print("took at least 20ms: {took >= 20ms}")
    print("took under a second: {took < 1s}")
}
    took at least 20ms: true
took under a second: true

    {took} writes the Duration in its units, like 20.1ms. Dividing by a unit gives a plain number, as in Integers. took / 1ms is the milliseconds and i64(took) the nanoseconds.

    time.since(start) is the same as time.clock() - start.

    Waiting

    sleep(d) waits for a Duration. Other tasks run while one task sleeps. In a select, an after(d) arm stops waiting on channels after that time. Both are built in and need no import. Tasks and channels shows them with tasks.

    To do something at a steady rate, such as a health check every few seconds, sleep until the next tick on the clock instead of for a fixed time. Then the time the work takes doesn't add up. A Duration of 0 or less doesn't wait.

    import time

void main() {
    start := time.clock()
    next := start

    for i in 1..4 {
        next += 10ms
        sleep(next - time.clock())
        print("health check {i}")
    }

    took := time.clock() - start
    print("three checks in at least 30ms: {took >= 30ms}")
}
    health check 1
health check 2
health check 3
three checks in at least 30ms: true
