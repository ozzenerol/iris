    S3

    Files that many machines share often go to an object store: Amazon S3, or a server that speaks its API, such as MinIO, Ceph or Cloudflare R2. The s3 module stores, reads, lists and removes objects, uploads big ones in parts, and makes links that work without keys. The sigv4 module signs the requests, and signs requests to the other AWS APIs too.

    The examples in this chapter need a server, so they read its address and keys from environment variables. A MinIO server for trying them runs with docker run -p 9000:9000 minio/minio server /data, whose keys are minioadmin and minioadmin.

    A client

    An s3.Client holds the keys, the region and the server. Every task and thread of a program can share one, and it keeps its connections open between requests. close closes them:

    import os, s3

!void main() {
    c := s3.Client{
        endpoint: os.env("S3_ENDPOINT") catch "http://localhost:9000",
        accessKey: os.env("S3_KEY") catch "minioadmin",
        secretKey: os.env("S3_SECRET") catch "minioadmin",
    }
    defer c.close()

    c.createBucket("photos") catch e {
        print("{e.code}")
    }
}
    • Without an endpoint the client talks to AWS in the given region (us-east-1 when none is given), with the bucket in the host name: https://photos.s3.eu-west-1.amazonaws.com/.
    • With an endpoint such as http://localhost:9000, the bucket is the first part of the path: http://localhost:9000/photos/.
    • sessionToken is for temporary keys, and ca names a file of certificates to trust instead of the system's.
    • A bucket that is already there fails with S3Error.conflict, wrong keys with S3Error.denied, and a missing bucket or key with S3Error.notFound.

    Objects

    put stores bytes under a key, with a content type. get gives them back, and getRange gives a part of them. head tells the size, ETag, type and time of an object without reading it, and exists whether it is there. delete removes it:

    import os, s3

!void main() {
    c := s3.Client{endpoint: "http://localhost:9000", accessKey: os.env("S3_KEY") catch "minioadmin",
        secretKey: os.env("S3_SECRET") catch "minioadmin"}
    defer c.close()

    try c.put("photos", "notes/today.txt", "buy milk\ncall Ada\n", "text/plain")

    scoped String text = try c.get("photos", "notes/today.txt")
    print(text)

    scoped s3.Info info = try c.head("photos", "notes/today.txt")
    print("{info.size} bytes of {info.contentType}")

    scoped String first = try c.getRange("photos", "notes/today.txt", 0, 2)
    print("starts with {first}")

    try c.delete("photos", "notes/today.txt")
    print("still there: {try c.exists("photos", "notes/today.txt")}")
}
    buy milk
call Ada

18 bytes of text/plain
starts with buy
still there: false

    A key may hold slashes, spaces and any other character. The slashes make it look like a path, but a bucket has no folders: notes/today.txt is one key.

    Listing

    list gives the objects whose keys start with a prefix, in key order, up to 1000 at a time. When truncated is set there are more, and the next page starts after the page's next. With a delimiter, keys that have it after the prefix are grouped into prefixes, the way a file browser shows folders:

    import os, s3

!void main() {
    c := s3.Client{endpoint: "http://localhost:9000", accessKey: os.env("S3_KEY") catch "minioadmin",
        secretKey: os.env("S3_SECRET") catch "minioadmin"}
    defer c.close()

    for key in ["2026/01/a.jpg", "2026/01/b.jpg", "2026/02/c.jpg", "readme.txt"] {
        try c.put("photos", key, "...")
    }

    scoped s3.Listing top = try c.list("photos", delimiter: "/")
    for p in top.prefixes {
        print("folder {p}")
    }
    for o in top.objects {
        print("file {o.key}, {o.size} bytes")
    }

    String after
    defer after.free()
    for {
        scoped s3.Listing page = try c.list("photos", prefix: "2026/", after: after, max: 2)
        for o in page.objects {
            print(o.key)
        }
        if !page.truncated {
            break
        }
        after.free()
        after = page.next.copy()
    }
}
    folder 2026/
file readme.txt, 3 bytes
2026/01/a.jpg
2026/01/b.jpg
2026/02/c.jpg

    Big objects

    A single put sends the whole object in one request. putLarge sends one bigger than a part (16 MiB unless partSize says otherwise, and 5 MiB at least) in parts, which S3 puts together at the end:

    try c.putLarge("backups", "db.tar", archive, "application/x-tar", partSize: 64MiB)

    startUpload gives an s3.Upload for sending the parts one at a time, for data that doesn't fit in memory at once. Each part but the last must be 5 MiB or more. finish puts them together, and abort drops them. An upload freed without finish is dropped too:

    scoped up := try c.startUpload("backups", "logs.tar")
for {
    scoped String chunk = try readNextChunk()
    if chunk.len == 0 {
        break
    }
    try up.part(chunk)
}
try up.finish()

    Links without keys

    presign makes a URL that anyone can use for a limited time, up to 7 days, with no keys: a link to download an object with GET, or to upload one with PUT:

    import http, os, s3

!void main() {
    c := s3.Client{endpoint: "http://localhost:9000", accessKey: os.env("S3_KEY") catch "minioadmin",
        secretKey: os.env("S3_SECRET") catch "minioadmin"}
    defer c.close()

    scoped String upload = try c.presign("PUT", "photos", "from-a-link.txt", 10m)
    scoped http.Reply r = try http.send("PUT", upload, "sent without keys")
    print("upload: {r.status}")

    scoped String download = try c.presign("GET", "photos", "from-a-link.txt", 1h)
    scoped http.Reply got = try http.get(download)
    print("download: {got.body}")
}
    upload: 200
download: sent without keys

    Signing other requests

    Every AWS API takes requests signed with Signature Version 4. A sigv4.Signer holds the keys, the region and the service, and sign gives the header lines that sign a request. They go with the request's own headers, which are signed too and must be sent as they are:

    import http, sigv4

!void main() {
    signer := sigv4.Signer{accessKey: "AKIA...", secretKey: "...", region: "eu-west-1", service: "sqs"}
    body := "Action=ListQueues&Version=2012-11-05"
    url := "https://sqs.eu-west-1.amazonaws.com/"

    List[str] headers
    defer headers.free()
    headers.push("Content-Type: application/x-www-form-urlencoded")
    List[String] signed = try signer.sign("POST", url, headers.items(), body)
    defer signed.freeEach()
    for h in signed {
        headers.push(h)
    }

    scoped http.Reply r = try http.send("POST", url, body, "", headers.items())
    print("{r.status}")
}

    presign gives a URL with the signature in its query, as the s3 module's presign does. signHash signs a body given by its SHA-256, or sigv4.UNSIGNED for one that isn't signed.
