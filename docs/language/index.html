Language

A tour of Iris, one topic per page. Each page builds on the ones before it.

  1. A first program: main, printing, comments and statements.
  2. Variables and types: declaring values and the built-in types.
  3. Functions: parameters, default and named arguments, several return values.
  4. Control flow: if, for and match.
  5. Text: str, String and putting values into strings.
  6. Structs: fields, literals, methods and embedding.
  7. Enums: plain enums and enums that carry data.
  8. Pointers and memory: pointers, slices, allocation, defer and scoped.
  9. Errors: !T, try and catch.
  10. Generics: generic structs and functions, interfaces.
  11. Collections: List, Map, and going over them with for.
  12. Modules: splitting a program up and using packages.
  13. Compile time: const, comptime, when and attributes.
  14. Concurrency: tasks, channels, threads and atomics.
  15. Calling C: C headers, callbacks, assembly and SIMD.
  16. Tools: the iris command, tests, formatting, editors and builds.
