Tools

The iris command builds, runs and tests programs, and manages packages.

Commands

CommandWhat it does
iris run main.iriscompiles and runs a program
iris build main.iriscompiles a program; -o name names the output
iris check main.irischecks a program without compiling it
iris ir main.irisprints the LLVM IR the compiler writes
iris testruns the tests
iris fmtformats the source files
iris get <package>adds a package to iris.mod
iris docshows the documentation from the comments
iris parse file.irisprints the syntax tree
iris lex file.irisprints the tokens

Tests

A test block can sit in any source file, next to the code it tests:

i64 add(i64 a, b) => a + b

test "add" {
    expect(add(2, 3) == 5)
    expect(add(-1, 1) == 0)
}

iris test runs every test block. Tests are left out of normal builds.

Build modes

ModeChecksOptimised
debugallno
release-safeindex checksyes
release-fastnoneyes
iris build --mode=release-safe main.iris

iris run and iris build use clang, version 15 or newer, to compile the IR. Set IRIS_CC to use a different one.

Other platforms

--target builds for another platform:

iris build --target=aarch64-linux
iris build --target=x86_64-linux
iris build --target=aarch64-macos

Debugging

Every build includes debug information, so gdb and lldb show Iris source lines and variable names.
