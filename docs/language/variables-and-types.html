Variables and types

How to declare values, and the types Iris has built in.

Declaring a variable

A declaration gives the type, then the name, then the value:

i64 count = 10
str name = "iris"

:= declares a variable and takes its type from the value:

count := 10        // i64
ratio := 0.5       // f64
ok := true         // bool
name := "iris"     // str

A variable declared without a value starts at zero: 0, false, an empty str or a null pointer.

i64 total
bool done

Constants

const gives a name to a value that never changes. The value is worked out when the program is compiled.

const MAX_CONN = 1024
const VERSION = "0.1.0"

Numbers

TypeSizeRange
i8, i16, i32, i641, 2, 4, 8 bytessigned integers
u8, u16, u32, u641, 2, 4, 8 bytesintegers from 0 up
f32, f644, 8 bytesfloating point

An integer literal is an i64 and a literal with a point is an f64. Long numbers can use _ between digits:

limit := 1_000_000
mask := 0xff
flags := 0b1010

bool

bool is true or false. Conditions must be bool: if n is an error, if n != 0 is correct.

Converting

A number converts on its own to a type that holds every value it can have, such as u8 to i64. Every other conversion is written as the type's name used like a function:

u8 b = 200
i64 n = b              // automatic: no value can be lost
u8 small = u8(n)       // written out: n might not fit
f64 avg = f64(total) / f64(count)

In a debug build, a conversion that loses a value stops the program with an error.

Floating point

f64 and f32 hold floating point numbers. A literal with a point or an exponent is an f64: 1.5, 2e10, 1e-3. An integer constant can be used where a float is expected, so x * 2 works when x is an f64. A variable of an integer type has to be converted: f64(n).

f32 converts to f64 on its own. Converting a float to an integer drops the fraction, toward zero; in a debug build a value that doesn't fit, or isn't a number, stops the program.

Division by zero gives infinity or NaN, as the hardware does. Floats are printed in the fewest digits that read back as the same number:

import math

void main() {
    f64 r = 2
    area := math.pi * r * r
    print("{area} {0.1 + 0.2} {1.0 / 3}")
    print("{i64(area)} {math.sqrt(2)} {1e21} {1.0 / 0.0}")
}
12.566370614359172 0.30000000000000004 0.3333333333333333
12 1.4142135623730951 1e+21 inf

Operators

OperatorsMeaning
+ - * / %arithmetic
& | ^ ~ << >>bits: and, or, xor, not, shifts
== != < <= > >=comparison
&& || !and, or, not, on bool
= += -= *= /= %= &= |= ^= <<= >>=assignment
a..bthe range from a to b, for for and match

They bind in this order, tightest first:

  1. * / % << >> &
  2. + - | ^
  3. == != < <= > >=
  4. &&
  5. ||
  6. ..

So a + b * c is a + (b * c), and x & 1 == 1 is (x & 1) == 1. Assignment is a statement, so it can't appear inside an expression.

Arithmetic happens in the type of its operands. Two u8 values add up as a u8, even when the result goes into an i64, so 200 + 100 overflows. Convert first when the result needs more room: i64(a) + i64(b).

Both sides of an operator must have the same type, or one must convert on its own to the other (u8 to i64). i32 + u32 is an error: write the conversion.

Durations and sizes

Numbers can carry a unit. Durations are ns, us, ms, s, m and h, and their type is Duration. Sizes are KiB, MiB and GiB, and they are plain integers.

sleep(200ms)
timeout := 30s
buf := alloc(u8, 64KiB)

Type aliases

type gives another name to a type. The two names mean the same type.

type Port = u16
type Handler = void(Request *, Response *)

Scope

A variable exists from its declaration to the end of its block. A variable in an inner block can't have the same name as one in an outer block of the same function.
