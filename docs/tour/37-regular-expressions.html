    Regular expressions

    The regex module finds patterns in text. The syntax is that of RE2: \d+ is one or more digits, (\w+) a group of word characters, a|b either one. A search takes time in proportion to the length of the text, whatever the pattern, so a pattern that comes from a user can't make a program hang.

    For text that a fixed separator cuts into parts, the methods of text in Text are simpler and faster. A regular expression is for text whose shape varies.

    Compiling a pattern

    regex.compile(pattern) turns a pattern into a Regex, or fails with RegexError.syntax when the pattern isn't valid. A Regex holds memory, so free it when it is done. Patterns are written as raw strings (r"..."), which keep backslashes as they are:

    import regex

!void main() {
    re := try regex.compile(r"^\d{1,3}(\.\d{1,3}){3}$")
    defer re.free()
    for addr in ["10.0.0.1", "10.0.0", "192.168.1.250", "host.lan"] {
        print("{addr}: {re.matches(addr)}")
    }
}
    10.0.0.1: true
10.0.0: false
192.168.1.250: true
host.lan: false

    matches says whether the pattern matches anywhere in the text. ^ and $ hold it to the start and the end, so here the whole text must be an address.

    A pattern written in the program is known to be valid. regex.must compiles it and panics if it isn't, so there is no error to handle:

    import regex

void main() {
    hex := regex.must(r"^[0-9a-f]+$")
    defer hex.free()
    print("{hex.matches("deadbeef")} {hex.matches("xyz")}")
}
    true false

    A pattern from a user or a file goes through compile. The error says what is wrong, and the byte where it was found:

    import regex

void main() {
    for p in [r"(\w+", r"a{2,1}", r"[z-a]"] {
        _ = regex.compile(p) catch e {
            print("{e.code}: {e.message}")
            regex.must("")
        }
    }
}
    RegexError.syntax: (\w+: a ( with no ) at 4
RegexError.syntax: a{2,1}: a repeat count over 1000, or the larger first at 6
RegexError.syntax: [z-a]: a range that ends before it starts at 4

    Finding a match

    find gives the first match and whether there was one. The Match gives the matched text with str, its place with start and end, and each group with group(i): group 0 is the whole match, group 1 the first (...). A match holds the places of its groups, so free it after use:

    import regex

void main() {
    re := regex.must(r"(\d+) ms")
    defer re.free()
    m, found := re.find("GET /health 200 in 14 ms")
    if found {
        print("[{m.str()}] at {m.start}..{m.end}, the number is {m.group(1)}")
    }
    m.free()
    m2, found2 := re.find("GET /health 200")
    print("found: {found2}")
    m2.free()
}
    [14 ms] at 19..24, the number is 14
found: false

    What str and group give are slices of the text that was searched, so that text must stay while the match is used. .copy() keeps one longer.

    Named groups

    (?P<name>...) gives a group a name, and re.index(name) gives its number. For a pattern with many groups, names keep the code readable. This reads the parts of an access log line:

    import regex

void main() {
    re := regex.must(r"""^(?P<ip>\S+) \S+ \S+ \[[^\]]+\] "(?P<method>[A-Z]+) (?P<path>\S+) [^"]*" (?P<status>\d{3}) (?P<bytes>\d+)""")
    defer re.free()
    ip := re.index("ip")
    method := re.index("method")
    path := re.index("path")
    status := re.index("status")
    line := r"""10.0.0.7 - - [24/Oct/2026:10:00:01 +0000] "GET /api/users HTTP/1.1" 200 5120"""
    m, found := re.find(line)
    if found {
        print("{m.group(ip)} {m.group(method)} {m.group(path)} -> {m.group(status)}")
    }
    m.free()
    print("{re.groups()} groups")
}
    10.0.0.7 GET /api/users -> 200
5 groups

    The pattern is written as r"""...""" because it has " in it. (?:...) groups without keeping, for | or a count over several characters, and doesn't take a number.

    A group that didn't take part in the match gives "", and span(i) gives -1, -1 for it, which tells it apart from a group that matched empty text:

    import regex

void main() {
    re := regex.must(r"^(\w+)(?::(\d+))?$")
    defer re.free()
    for addr in ["db:5432", "cache"] {
        m, _ := re.find(addr)
        s, e := m.span(2)
        print("host {m.group(1)}, port [{m.group(2)}] at {s}..{e}")
        m.free()
    }
}
    host db, port [5432] at 3..7
host cache, port [] at -1..-1

    Every match

    findAll gives every match, left to right, in a List. Each match and the list are freed after use:

    import regex

void main() {
    re := regex.must(r"#(\w+)")
    defer re.free()
    ms := re.findAll("deploy #api and #worker, then #db")
    for m in ms {
        print(m.group(1))
        m.free()
    }
    ms.free()
}
    api
worker
db

    A limit stops after that many matches: re.findAll(text, 2). To read the text between matches, split cuts at each one:

    import regex

void main() {
    re := regex.must(r"\s*[,;]\s*")
    defer re.free()
    scoped List[str] hosts = re.split("db1, db2;db3 ,  db4")
    for h in hosts {
        print("[{h}]")
    }
}
    [db1]
[db2]
[db3]
[db4]

    Replacing

    replace gives new text with each match replaced. In the replacement, $1 is group 1, ${name} a named group and $$ a $. A replacement with ${name} is a raw string, so its braces aren't read as values:

    import regex

void main() {
    re := regex.must(r"(?P<user>[\w.]+)@(?P<host>[\w.]+)")
    defer re.free()
    scoped String masked = re.replace("from ada@example.com to ops@lan", r"***@${host}")
    print(masked)
    secrets := regex.must(r"(token|password)=\S+")
    defer secrets.free()
    scoped String clean = secrets.replace("login user=ada password=hunter2 token=abc123", "$1=[hidden]")
    print(clean)
    scoped String first = secrets.replace("token=a token=b", "$1=x", 1)
    print(first)
}
    from ***@example.com to ***@lan
login user=ada password=[hidden] token=[hidden]
token=x token=b

    The last argument is the most matches to replace, here only the first.

    Flags

    A flag at the start of a pattern changes how the rest of it matches. (?i) matches letters in either case, (?m) lets ^ and $ match at the start and end of every line, and (?s) lets . match a newline:

    import regex

void main() {
    level := regex.must(r"(?i)\b(error|warn)\b")
    defer level.free()
    print("{level.matches("ERROR disk full")} {level.matches("Warn: slow")} {level.matches("errors: 0")}")

    keys := regex.must(r"(?m)^(\w+)=")
    defer keys.free()
    ms := keys.findAll("host=db\nport=5432\n# a comment\nuser=app\n")
    for m in ms {
        print(m.group(1))
        m.free()
    }
    ms.free()
}
    true true false
host
port
user

    \b is a word boundary, so errors doesn't count as error. (?i:...) sets a flag for one group only.

    Checking input

    A program that takes values from users or files checks them with patterns compiled once and kept. A struct holds them, and its free frees them all:

    import regex

struct Rules {
    regex.Regex name
    regex.Regex port
}

Rules rules() => Rules{name: regex.must(r"^[a-z][a-z0-9-]{0,62}$"), port: regex.must(r"^\d{1,5}$")}

void Rules.free() {
    self.name.free()
    self.port.free()
}

void main() {
    scoped Rules r = rules()
    str[3] names = ["api-1", "Api", "db"]
    str[3] ports = ["8080", "80", "54321x"]
    for i in 0..3 {
        name := names[i]
        port := ports[i]
        if !r.name.matches(name) {
            print("{name}: a name is lower case letters, digits and -")
        } else if !r.port.matches(port) {
            print("{name}: {port} isn't a port")
        } else {
            print("{name}:{port} is fine")
        }
    }
}
    api-1:8080 is fine
Api: a name is lower case letters, digits and -
db: 54321x isn't a port
