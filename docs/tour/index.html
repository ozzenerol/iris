    Language Tour

    The whole language, one topic per chapter, with runnable programs and their output. Read it in order once, then use it as the reference.

    1. 1A first programThe parts of every Iris program: main, statements, blocks and comments, and the commands that build and run it.
    2. 2VariablesHow to declare variables, change them, and where each one is visible.
    3. 3IntegersThe integer types, their literals, arithmetic, and conversion between them.
    4. 4Floating pointThe two float types, their literals and printing, and how they mix with integers.
    5. 5Booleans and operatorsThe bool type, the operators, and the order in which an expression is evaluated.
    6. 6TextIris has two text types. A str views text stored elsewhere. A String owns its text and can grow. This chapter covers both, text literals, and the methods on text.
    7. 7Values in textInterpolating values with braces, the format function, and how temporary text is freed.
    8. 8if and matchif chooses by condition and match by value. Both can produce a value.
    9. 9Loopsfor is the only loop. It has four forms: forever, while a condition holds, over a range, and over items. break and continue control it.
    10. 10FunctionsDeclaring functions, default and named arguments, variadic parameters, and returning several values.
    11. 11Functions as valuesFunctions can be stored in variables and struct fields and passed as arguments.
    12. 12Arrays and slicesAn array holds a fixed number of values in a row. A slice views some of them, or memory from alloc, and knows its length. Most functions take slices.
    13. 13StructsA struct groups named values into one type. This chapter covers declaring structs, literals and defaults, copying and comparing, embedding, and memory layout.
    14. 14MethodsA method is a function that belongs to a struct. This chapter covers self, constructor and free conventions, and the methods the language itself calls.
    15. 15EnumsAn enum is a type with a fixed list of values. Plain enums name choices and codes. Flags enums hold any set of their values. Enums with data carry fields per value.
    16. 16Tuples and type aliasesTuples carry a function's several results. Type aliases give a type a second name.
    17. 17PointersA pointer holds the address of a value, so code can read and change the value in place. This chapter covers addresses, dereferencing, null, and how long a pointer stays valid.
    18. 18ErrorsA function that can fail says so in its type and returns either its result or an error. The caller must pass the error up with try or handle it with catch. This chapter covers creating, propagating and handling errors, the trace printed when an error leaves main, and panic for bugs.
    19. 19MemoryIris has no garbage collector. Memory that a program asks for, it gives back. This chapter covers where values live, alloc and free, the statements that make freeing hard to forget (defer, errdefer and scoped), arenas, who frees what, and the checks that catch mistakes.
    20. 20GenericsA generic function or struct is written once, with type parameters, and used with many types. This chapter covers both, how the types are worked out, and how generic code is compiled.
    21. 21InterfacesAn interface is a list of methods. A struct with those methods has the interface, with nothing more to write. Interfaces work in two ways: as bounds on type parameters, resolved at compile time, and as dyn values, resolved at run time.
    22. 22Collections
    23. 23ModulesA program is split into modules. A module is a folder of files that share their names and show other modules only what they mark pub. This chapter covers programs and projects, pub, import, the standard library, and packages from other projects.
    24. 24Tasks and channelsA task is a function call that runs alongside the rest of the program. Tasks take turns on a thread and switch whenever one waits, so a program can do many things at once without callbacks. Channels pass values between them. This chapter covers spawn, channels, select and timers.
    25. 25ThreadsThreads run at the same time on different CPU cores. This chapter covers starting and joining them, sharing data between them with Atomic and Mutex, and threadlocal.
    26. 26Compile timeThe compiler can do work while it builds the program: constants, values computed by running code before the program exists, and code kept or left out by the platform it is built for. There is no preprocessor and there are no macros. All of this is ordinary Iris.
    27. 27AttributesAn attribute starts with @ and goes on the line before a declaration. Some make the compiler write code for a struct that reads it from environment variables, from command-line flags or from JSON. Others change how a function is compiled. This chapter covers each one except @json and @flags, which have their own chapters: JSON and Command-line flags.
    28. 28Calling CIris calls C functions directly, with no wrapper code to write. import c reads a C header and makes its functions, types and constants available. C can also call Iris functions back. This chapter covers both, how C types look in Iris, and the rules for text and memory at the border.
    29. 29TestingTests sit next to the code they test, in test blocks, and iris test runs them. This chapter covers writing tests, checking with expect, tests that use errors, running them, and measuring speed with bench blocks.
    30. 30ToolsThe iris command builds, runs, tests, formats and documents programs, gets packages and serves editors. This chapter covers each command, the build modes, building for other platforms, editors and debuggers.
