    Guides

    Whole programs, built one step at a time, with every changed function shown in full.

    1. 1Build a REST APIThis guide builds a small service from an empty folder: it keeps notes in a SQLite database and serves them as JSON over HTTP. Each step ends with a program that runs, and the commands to try it.
    2. 2Build a command-line toolThis guide builds sizes from an empty folder: a tool that shows what takes the space in a folder. It reads flags, lines its output up in a table with colors, shows a progress bar, and can ask for folders one after another with an editable prompt. Each step ends with a program that runs, and the commands to try it.
    3. 3Build a TCP chat serverThis guide builds chat from an empty folder: a server that people connect to over TCP, give a name, and then talk. Each line one of them types goes to everyone else. It uses the three ways Iris does several things at once. A task for each connection waits on that client and nothing else. Channels carry messages between the tasks. Threads accept connections on several CPU cores at the same time. Each step ends with a program that runs, and the commands to try it.
    4. 4Build a DNS serverThis guide builds dns from an empty folder: a DNS server for the names of a small network. A program asks it for web.lan and gets the addresses back. The dns module reads the bytes of each query into a message and writes the reply back as bytes, so the program works with names, kinds and addresses. The server speaks UDP. Each step ends with a program that runs, and the commands to try it.
    5. 5Build a UDP counter serverThis guide builds counters from an empty folder: a server that other programs tell what happened, like hits:1 for a page that was shown or errors:1 for a request that failed. It adds up the numbers, and says the totals when asked. Programs send it lines over UDP, where each message is one datagram that goes out at once, with no connection to open first and no answer to wait for. Each step ends with a program that runs, and the commands to try it.
